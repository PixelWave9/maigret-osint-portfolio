MAIGRET v0.5.0

OSINT // USERNAME HUNTING // DIGITAL FOOTPRINT RECONNAISSANCE FIELD MANUAL
BLACKARCH READY 3000+ SITES STEALTH MODE FOR AUTHORIZED OSINT ONLY

هاد الأداة ماشي للعب. Maigret هو أقوى محرك بحث عن اليوزرنيم فالعالم. كيقلب على الأثر الرقمي ديالك أو ديال الهدف فأكثر من 3000 موقع. هاد الدليل غادي يعلمك كيفاش تستعمل كل أمر بلا اختصار.

0x01 // ما هي MAIGRET وعلاش هي أخطر من Sherlock

Maigret هي نسخة مطورة ومحسنة من Sherlock. الفرق الجوهري: كتدير Recursive Search - يعني إلا لقات بروفايل، كتجبد منو أسماء أخرى، إيميلات، ID أخرى وكتقلب عليهم أوتوماتيكيا. هادشي كيديرها سلاح استخبارات حقيقي.

OPERATOR NOTE: استعملها فقط على أهداف عندك إذن قانوني للبحث عليها، أو على راسك باش تعرف الأثر الرقمي ديالك. أي استعمال للتحرش أو المطاردة هو جريمة.

0x02 // الهدف الأساسي - USERNAMES

USERNAMES [positional argument]
// WHAT IT DOES - للمبتدئ

هذا هو الهدف. اسم المستخدم اللي بغيتي تقلب عليه. تقدر تعطي واحد أو عشرة فدقة وحدة.

// WHY USE IT

بلا هادشي الأداة ما غاديش تخدم. هو نقطة البداية ديال أي عملية OSINT.

// TECHNICAL DEEP DIVE

Maigret كتاخد اليوزرنيم وكتدوزو على قاعدة بيانات JSON فيها أكثر من 3000 موقع، كل موقع عندو URL pattern وطريقة كشف وجود الحساب (status_code, message, redirect). كتدير request لكل موقع وتقرر واش كاين ولا لا.

// BEGINNER EXAMPLE
maigret abhx696
// ADVANCED EXAMPLE - CHAIN
maigret abhx696 john_doe_1337 elonmusk --top-sites 1000
PRO TIP: بدا ديما بيوزرنيم واحد باش تفهم النتائج، من بعد دوز للبحث الجماعي.

0x03 // التحكم الأساسي - CORE NETWORK & PERFORMANCE

-h, --help
// WHAT IT DOES

كيوريك هاد اللائحة اللي شفتي. دليل المساعدة الخام.

maigret --help
--version
// WHAT IT DOES

كيوريك إصدار Maigret والمكتبات اللي خدام بها.

// WHY

مهم باش تعرف واش عندك آخر إصدار، حيث المواقع كتموت وكتزاد يوميا.

maigret --version
--timeout TIMEOUT [default: 30s]
// WHAT IT DOES - للمبتدئ

الوقت اللي كتسناه الأداة قبل ما تقول هاد الموقع ما جاوبش. إلا كان الموقع ثقيل، زيد الوقت.

// TECHNICAL DEEP DIVE

كل request عندو socket timeout. إلا كان 30 ثانية بزاف قصيرة لمواقع بطيئة، غادي تعطيك False Negative. زيادة timeout كتزيد الدقة ولكن كتطول مدة الفحص.

// BEGINNER
maigret abhx696 --timeout 60
// ADVANCED - SLOW TARGETS
maigret abhx696 --timeout 90 --retries 3
COMMON MISTAKE: ما تديرش timeout قليل بزاف (10s) غادي تضيع بزاف ديال النتائج.
--retries RETRIES
// WHAT IT DOES

شحال من مرة غادي تعاود المحاولة إلا فشل الطلب بسبب مشكل شبكة مؤقت.

maigret abhx696 --retries 2
maigret target --retries 5 --timeout 60 # عملية صبورة ضد مواقع محمية
-n, --max-connections CONNECTIONS [default: 100]
// WHAT IT DOES

عدد الطلبات المتزامنة. 100 تعني 100 موقع كيتقلب عليهم فنفس الوقت.

// WHY IMPORTANT

إلا زدتيه بزاف (500) غادي تسرع ولكن المواقع غادي تبلوكيك وتعتبرك هجوم DDoS. إلا نقصتيه (10) غادي تكون stealth أكثر ولكن بطيء.

maigret abhx696 -n 50 # متوازن وآمن
maigret abhx696 -n 10 --proxy socks5://127.0.0.1:1080 # بطيء ومتخفي
--no-recursion
// WHAT IT DOES

كتعطل أقوى ميزة ف Maigret. بلا recursion، غادي يقلب غير على اليوزرنيم اللي عطيتيه. بالـ recursion، إلا لقى بروفايل فيه يوزرنيم آخر، غادي يقلب عليه حتى هو.

// WHEN TO DISABLE

إلا كنتي بغيتي نتيجة سريعة ومحددة فقط، أو إلا بغيتي تتجنب الضوضاء.

maigret abhx696 --no-recursion
--no-extracting
// WHAT IT DOES

كيمنع استخراج بيانات إضافية من صفحات البروفايل (إيميلات، أسماء حقيقية، روابط).

maigret abhx696 --no-extracting # بحث سطحي سريع
maigret abhx696 # الحالة العادية - استخراج كامل للمعلومات
--id-type {username, yandex_public_id, gaia_id, vk_id, ok_id, wikimapia_uid, steam_id, uidme_uguid, yelp_userid}
// WHAT IT DOES - مهم جدا

ماشي ديما كنقلبو بيوزرنيم. مرات كيكون عندك ID ديال Google (gaia_id) أو VK أو Steam. هاد الأمر كيقول ل Maigret نوع المعرف اللي عندك.

// BEGINNER
maigret 123456789 --id-type gaia_id # البحث ب Google ID
// ADVANCED
maigret 76561198123456789 --id-type steam_id --all-sites
--permute
// WHAT IT DOES

إلا عطيتيه جوج يوزرنيم أو أكثر، غادي يولد تركيبات جديدة منهم. مثلا abhx + 696 = abhx696, 696abhx, abhx_696...

maigret abhx 696 --permute
maigret john doe --permute --top-sites 500 # توليد كل الاحتمالات
--db DB_FILE
// WHAT IT DOES

كتقدر تحمل قاعدة بيانات مواقع مخصصة ديالك من ملف JSON أو من رابط HTTP. مفيد إلا بغيتي تزيد مواقع خاصة بشركة أو دولة معينة.

maigret abhx696 --db ./my_custom_sites.json
maigret abhx696 --db https://raw.githubusercontent.com/soxoj/maigret/main/maigret/resources/data.json
--cookies-jar-file COOKIE_FILE
// WHAT IT DOES

كتستعمل ملف كوكيز باش تدخل لمواقع كتطلب تسجيل دخول. بلا كوكيز، بزاف المواقع ما كتعطيش نتيجة صحيحة.

maigret abhx696 --cookies-jar-file cookies.txt
--ignore-ids IGNORED_IDS
// WHAT IT DOES

كتقول ليه تجاهل هاد اليوزرنيم أو ID فالبحث التكراري. باش ما يبقاش يدور فحلقة مفرغة.

maigret abhx696 --ignore-ids admin,root,test
--folderoutput, -fo PATH
// WHAT IT DOES

إلا قلبتي على بزاف ديال اليوزرنيم، النتائج غادي تتخزن فهاد المجلد، كل واحد فملف بوحدو.

maigret user1 user2 user3 -fo ./results/
--proxy, -p PROXY_URL | --tor-proxy | --i2p-proxy
// WHAT IT DOES - أخطر أوامر التخفي

هادو هما أوامر التخفي الحقيقي. --proxy كتدوز كل الترافيك عبر بروكسي. --tor-proxy كتستعمل شبكة Tor باش تخفي الهوية ديالك. --i2p-proxy لشبكة I2P.

// BEGINNER - TOR
maigret abhx696 --tor-proxy socks5://127.0.0.1:9050
// ADVANCED - ROTATING PROXY
maigret abhx696 -p socks5://127.0.0.1:1080 -n 20 --timeout 90 # بطيء ولكن لا يمكن تتبعه
OPERATOR WARNING: ما تخدمش بلا بروكسي إلا كنتي كتقلب على راسك. فعمليات حقيقية، ديما استعمل Tor.
--with-domains
// WHAT IT DOES - تجريبي

ميزة تجريبية كتقلب واش كاين دومينات مسجلة بنفس اسم اليوزرنيم. مثلا abhx696.com

maigret abhx696 --with-domains
--reports-sorting {default, data}
// WHAT IT DOES

كيفاش غادي يترتبو النتائج فالتقارير. default = حسب الترتيب اللي تلقاو فيه. data = حسب كمية البيانات اللي تلقات.

maigret abhx696 --reports-sorting data -H

0x04 // فلترة الأهداف - SITE FILTERING

-a, --all-sites
// WHAT IT DOES

كيقلب فجميع المواقع اللي كاينة فقاعدة البيانات (أكثر من 3000). بطيء جدا ولكن شامل.

maigret abhx696 -a
PRO TIP: ما تستعملوش فالبداية. بدا بـ --top-sites 500 ومن بعد إلا ما لقيتي والو دوز لـ -a.
--top-sites N [default: 500]
// WHAT IT DOES

كيقلب غير فأشهر N موقع حسب ترتيب Alexa. 500 هو الافتراضي ومتوازن.

maigret abhx696 --top-sites 100 # سريع جدا للاختبار
maigret abhx696 --top-sites 1000 # تغطية واسعة
--tags TAGS
// WHAT IT DOES

كتفلتر المواقع حسب النوع. مثلا كتبغي غير مواقع التواصل، أو منتديات، أو مواقع إباحية، أو ألعاب...

// HOW TO KNOW TAGS

استعمل --stats باش تشوف جميع الـ tags المتاحة.

maigret abhx696 --tags social,photo # غير انستا وتيك توك وفيسبوك
maigret abhx696 --tags dating,porn # للتحقيقات الحساسة
maigret abhx696 --tags gaming,code # للهاكرز والمبرمجين
--site SITE_NAME [multiple]
// WHAT IT DOES

كتحدد مواقع بعينها فقط. تقدر تستعملو بزاف ديال المرات.

maigret abhx696 --site GitHub --site Instagram --site Twitter
maigret abhx696 --site "Reddit" --site "TikTok" --site "Spotify"
--use-disabled-sites
// WHAT IT DOES

كاين مواقع معطلة فالقاعدة حيث كتعطي نتائج كاذبة بزاف. هاد الأمر كيرجعها للخدمة. خطر - كيزيد False Positives.

maigret abhx696 --use-disabled-sites --top-sites 1000

0x05 // أوضاع العمليات الخاصة - OPERATING MODES

--parse URL
// WHAT IT DOES - سلاح قوي

كتعطيه رابط بروفايل (مثلا رابط انستغرام)، وهو كيستخرج منو اليوزرنيم وكل الـ IDs اللي كاينين فالصفحة ويبدا يقلب عليهم.

maigret --parse https://www.instagram.com/abhx696/
maigret --parse https://twitter.com/elonmusk # استخراج كل ش
